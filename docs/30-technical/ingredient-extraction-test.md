## わかった技術的なポイント（実装時に反映する）
- **X**：公式の有料APIを使わず、埋め込み表示用の入口から、投稿の本文・画像・引用元の投稿・リンク先を取れる。ただし公式に保証された方法ではないため、将来使えなくなる可能性がある
- **Xの短縮リンク（t.co）**：転送先がページ内に書かれているので、それをたどる必要がある
- **Instagram**：通常のアクセスでは中身を取れないが、リンクプレビュー用の情報（ページの説明文）に投稿文がまるごと入っている。SNSアプリがリンクのプレビューを作るときの名乗り方でアクセスすると取得できる。公式に保証された方法ではないため、将来使えなくなる可能性がある
- **レシピサイト**：多くのサイトはページ内に「材料一覧を整理したデータ（構造化データ）」を持っているので、それを優先して使う
- **推測しかできない場合**：URLから推測しかできなかったときは、画像も読んで、実際に書かれた材料が取れた方を採用する
- **大きな画像**：スマホのスクショは3MB近いものがある。本番では縮小してから送る
- AIへの指示で、「水」は材料から外す

## Gemini の使い方（2026-09時点で確認）
- 部品：`@google/genai`（2.24.0）。Googleが今すすめている Interactions API（`client.interactions.create`）を使う
- 出力の形は `response_format: { type: "text", mime_type: "application/json", schema }` で指定し、結果は `interaction.output_text` から読む
- 画像は `{ type: "image", data: <base64>, mime_type }` で渡す
- `store: false` を指定して、Google側にやりとりを保存しない
- 鍵は環境変数 `GEMINI_API_KEY`
- 料金：入力 $0.75 ／ 出力 $3.75（100万トークンあたり、2026年末まで。2027年1月から2倍）
